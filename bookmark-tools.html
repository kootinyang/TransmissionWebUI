🎛️ 功能开关控制面板

Transmission Web Interface 调试功能开关

📊 种子列表假数据

启用后会显示8个测试种子，用于调试样式。支持实时速度波动和进度模拟。

通过控制台切换
按 F12 打开控制台，粘贴以下命令
// 启用假数据 localStorage.setItem('mock_torrents_enabled', 'true'); // 禁用假数据 localStorage.setItem('mock_torrents_enabled', 'false'); // 刷新页面查看效果 location.reload();
通过 URL 参数切换
临时切换，不会保存设置
// 启用 http://localhost:9091/transmission/web/?mock_torrents=true // 禁用 http://localhost:9091/transmission/web/?mock_torrents=false
提示：三种方式优先级：URL参数 > localStorage > 代码默认配置

🔔 连接失败弹窗

当后端服务不可用时是否显示"Connection failed"弹窗。

通过控制台切换
按 F12 打开控制台，粘贴以下命令
// 显示弹窗（恢复原始行为） localStorage.setItem('show_connection_alert', 'true'); // 屏蔽弹窗 localStorage.setItem('show_connection_alert', 'false'); // 刷新页面查看效果 location.reload();

📝 当前状态查看

在控制台执行以下命令查看当前所有开关状态：

console.log('=== 功能开关状态 ==='); console.log('假数据:', localStorage.getItem('mock_torrents_enabled') || '默认'); console.log('连接弹窗:', localStorage.getItem('show_connection_alert') || '默认'); console.log('===================');

🗑️ 清除所有设置

恢复所有功能到代码默认配置：

localStorage.removeItem('mock_torrents_enabled'); localStorage.removeItem('show_connection_alert'); alert('设置已清除，刷新页面生效'); location.reload();
