  重组方案

  按 UI 区域 将代码重新归类，每个区域内部遵循 自上而下、自左而右 的顺序（即从外
  层容器到内层元素，从左到右的排列顺序），区域之间插入一行注释分隔。

  建议的 10 大区域划分：

  ┌─────────────────────────────────────────────────────────────┐
  │ 1. CSS Variables & Global Base                               │
  │    :root → html/body → img/a → .hidden                       │
  ├─────────────────────────────────────────────────────────────┤
  │ 2. Main Window Layout                                        │
  │    #mainwin → #mainwin-workarea → #torrent-container         │
  ├─────────────────────────────────────────────────────────────┤
  │ 3. Toolbar                                                   │
  │    #mainwin-toolbar → buttons → #toolbar-overflow            │
  ├─────────────────────────────────────────────────────────────┤
  │ 4. Status Bar                                                │
  │    #mainwin-statusbar → #torrent-search → #turtle → speeds   │
  ├─────────────────────────────────────────────────────────────┤
  │ 5. Torrent List                                              │
  │    #torrent-list → .torrent → .icon → .torrent-name →        │
  │    .torrent-labels → .torrent-progress-* → states            │
  ├─────────────────────────────────────────────────────────────┤
  │ 6. Inspector Side Panel                                      │
  │    .tabs-container → .tabs-buttons → .tabs-pages →           │
  │    .inspector-info-page → .inspector-card → .inspector-row   │
  ├─────────────────────────────────────────────────────────────┤
  │ 7. Inspector Sub-pages (Peers / Tiers / Files)               │
  │    .peer-list → .tiers-page → .files-page → #inspector-file-list │
  ├─────────────────────────────────────────────────────────────┤
  │ 8. Preferences Dialog                                        │
  │    #prefs-dialog → .tabs-page → .prefs-card → inputs         │
  ├─────────────────────────────────────────────────────────────┤
  │ 9. Menus (Context Menu + Overflow Menu)                      │
  │    .context-menu → .overflow-menu → animations               │
  ├─────────────────────────────────────────────────────────────┤
  │ 10. Popups & Dialogs                                         │
  │    dialog → .dialog-container → .popup.* → .dialog-window    │
  ├─────────────────────────────────────────────────────────────┤
  │ 11. Responsive & Media Queries                               │
  │    @media (max-width: 768px) → @media (width < 600px) etc   │
  └─────────────────────────────────────────────────────────────┘

  ---
  每个区域内部的排序规则：

  ┌──────────┬──────────────────────────────────────────────────────────────┐
  │ 排序维度 │                             规则                             │
  ├──────────┼──────────────────────────────────────────────────────────────┤
  │ 自上而下 │ 父元素在前，子元素在后。例如 #torrent-list → .torrent →      │
  │          │ .icon → .torrent-name                                        │
  ├──────────┼──────────────────────────────────────────────────────────────┤
  │          │ 同一层级按 DOM 从左到右顺序。例如工具栏按钮按 #toolbar-open  │
  │ 自左而右 │ → #toolbar-delete → #toolbar-start → #toolbar-pause →        │
  │          │ #toolbar-inspector                                           │
  ├──────────┼──────────────────────────────────────────────────────────────┤
  │ 状态变体 │ 基础样式在前，状态样式（:hover、.selected、.paused）在后     │
  ├──────────┼──────────────────────────────────────────────────────────────┤
  │ 伪元素   │ 元素本身在前，::before / ::after 紧随其后                    │
  └──────────┴──────────────────────────────────────────────────────────────┘

  ---
  区域分隔注释格式：

  /* ═══════════════════════════════════════════════════════════ */
  /* 1. CSS Variables & Global Base                              */
  /* ═══════════════════════════════════════════════════════════ */

  /* ─────────────────────────────────────────────────────────── */
  /* 2. Main Window Layout                                       */
  /* ─────────────────────────────────────────────────────────── */

  /* ─────────────────────────────────────────────────────────── */
  /* 3. Toolbar                                                  */
  /* ─────────────────────────────────────────────────────────── */

  （第 1 个区域用双横线 ══════，其余用单横线 ──────，视觉上突出全局变量区）
