# 功能开关使用说明

## 新增功能

已为以下两个功能添加可配置开关，支持随时切换：

1. **连接失败弹窗屏蔽**
2. **种子列表假数据**

---

## 快速开始

### 方式一：浏览器控制台（推荐）

按 `F12` 打开控制台，执行以下命令：

```javascript
// ===== 种子列表假数据 =====
// 启用
localStorage.setItem('mock_torrents_enabled', 'true');

// 禁用
localStorage.setItem('mock_torrents_enabled', 'false');

// ===== 连接失败弹窗 =====
// 显示弹窗（恢复原始）
localStorage.setItem('show_connection_alert', 'true');

// 屏蔽弹窗
localStorage.setItem('show_connection_alert', 'false');

// ===== 刷新页面生效 =====
location.reload();
```

### 方式二：URL 参数（临时）

在地址栏添加参数：

```
启用假数据：  ?mock_torrents=true
禁用假数据：  ?mock_torrents=false
```

### 方式三：书签工具（一键切换）

拖拽以下链接到书签栏：

- [切换假数据](javascript:(function(){var curr=localStorage.getItem('mock_torrents_enabled');var next=curr==='true'?'false':'true';localStorage.setItem('mock_torrents_enabled',next);alert('假数据: '+(next==='true'?'开启':'关闭')+'\n刷新页面生效');location.reload();})())
- [切换连接弹窗](javascript:(function(){var curr=localStorage.getItem('show_connection_alert');var next=curr==='true'?'false':'true';localStorage.setItem('show_connection_alert',next);alert('连接弹窗: '+(next==='true'?'开启':'关闭')+'\n刷新页面生效');location.reload();})())

## 优先级说明

开关生效的优先级（从高到低）：

1. **URL 参数** - 临时生效，适合测试
2. **localStorage** - 持久保存，适合长期使用
3. **代码配置** - 默认行为，修改 `CONFIG.enable` 等

---

## 假数据配置

编辑 `mock-torrents.js` 可调整：

```javascript
const CONFIG = {
  enable: true,                    // 主开关
  enableRealtimeUpdate: true,      // 是否实时波动
  updateInterval: 1000             // 更新间隔(ms)
};
```

## 常见问题

**Q: 修改后不生效？**
A: 必须刷新页面才能生效。

**Q: 如何查看当前状态？**
A: 控制台执行：`localStorage.getItem('mock_torrents_enabled')`

**Q: 能否保存设置到文件？**
A: localStorage 会自动保存到浏览器，或修改代码中的默认值。

**Q: 多人协作如何统一配置？**
A: 直接修改代码中的 `CONFIG.enable` 默认值。

---

## 一键恢复默认

```javascript
localStorage.removeItem('mock_torrents_enabled');
localStorage.removeItem('show_connection_alert');
location.reload();
```
